# Jurnal Internasional Tambahan (\u2265 2023)

10 jurnal/conference proceedings internasional yang dipilih untuk memperkuat literatur skripsi *"Analisis Performa Post-Training Quantization (PTQ) pada Small Language Model untuk Implementasi Edge Computing Berbasis Android"*. Semua referensi dipublikasikan pada tahun 2023 atau lebih baru dan dipilih berdasarkan tiga klaster topik:

- **Klaster A \u2014 Benchmark LLM/SLM pada Perangkat Mobile/Edge** (4 referensi)
- **Klaster B \u2014 Metodologi Kuantisasi & Optimasi pada CPU ARM** (4 referensi)
- **Klaster C \u2014 Arsitektur Model yang Diuji (LFM 2 dan Qwen 3)** (2 referensi)
