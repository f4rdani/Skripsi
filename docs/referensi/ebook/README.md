# Ebook Pendukung Skripsi

Dua ebook akademis pendukung skripsi *"Analisis Performa Post-Training Quantization (PTQ) pada Small Language Model untuk Implementasi Edge Computing Berbasis Android"*. Kedua ebook dipublikasikan oleh O'Reilly Media dan secara langsung relevan dengan topik *TinyML / Edge AI* yang menjadi konteks penelitian.
