DAFTAR SIMBOL                                                                xi

Berisi simbol matematis, simbol grafis pada diagram, serta singkatan teknis yang
muncul di seluruh naskah skripsi. Simbol disusun mengikuti urutan kemunculan.

A. SIMBOL MATEMATIS
| Simbol | Nama / Bacaan        | Penjelasan                                                       |
|--------|----------------------|------------------------------------------------------------------|
| Δ      | Delta                | Selisih atau perubahan nilai antara dua pengukuran.               |
| ≈      | Kira-kira            | Pendekatan numerik (mis. ≈ 8 GB).                                  |
| ≤      | Kurang dari atau sama| Batas atas suatu nilai.                                            |
| ≥      | Lebih dari atau sama | Batas bawah suatu nilai.                                           |
| ±      | Plus-minus           | Margin error pada hasil pengukuran (mis. mean ± standar deviasi).  |
| ×      | Kali / multiplikator | Rasio relatif (mis. 0,310× = 31 % dari nilai acuan).               |
| ⁻¹     | Invers / negative-1  | Kebalikan suatu nilai (mis. PPL⁻¹ = 1/PPL).                         |
| ∝      | Proporsional         | Berbanding lurus terhadap suatu variabel.                          |
| α      | Alfa                 | Tingkat signifikansi statistik (mis. α = 0,05).                    |
| σ      | Sigma                | Standar deviasi populasi.                                          |
| μ      | Mu                   | Rerata (mean) populasi.                                            |
| n      | n-sampel             | Jumlah sampel pengamatan.                                          |

B. SIMBOL GRAFIS PADA DIAGRAM
| Simbol            | Penjelasan                                                                  |
|-------------------|-----------------------------------------------------------------------------|
| Kotak rounded biru (default)  | Node netral: proses, modul, data, atau model.                    |
| Kotak rounded merah (alert)   | Node masalah / risiko / batas yang harus dihindari.              |
| Kotak rounded hijau (success) | Node target, hasil, atau kondisi yang diinginkan.                |
| Kotak rounded abu-abu         | Node aktor (pengguna, peneliti) atau konteks lingkungan.         |
| Panah →                       | Alur sebab-akibat / urutan proses (sumber → tujuan).              |
| Panah ⇒                       | Implikasi atau kesimpulan yang ditarik.                          |
| Garis putus-putus             | Hubungan opsional / referensial, bukan alur eksekusi utama.       |

Catatan konsistensi: seluruh diagram pada Bab I–IV menggunakan tiga warna utama
(biru = default, merah = alert, hijau = success) dan satu bentuk node tunggal
berupa rounded rectangle. Tidak ada ikon eksternal (foto, gambar) di dalam node;
seluruh keterangan disampaikan dalam bentuk teks agar simbol tetap seragam.
